Error Debugging

Error Message
TypeError: Cannot read properties of undefined (reading 'map')
    at App.tsx:45:12
↓
Resto Debug Analysis
WHAT: map called on undefined
WHY: Variable `items` not initialized or API returned null
FIX: Add guard: const items = data?.items ?? []

Quick Start

Get up and running in minutes

# Clone the repository git clone https://github.com/LimeAPI/resto.git cd resto # Install dependencies npm install # Build the server npm run build

Configure Your IDE

Choose your preferred development environment

claude_desktop_config.json
{ "mcpServers": { "resto": { "command": "node", "args": ["/absolute/path/to/resto/dist/index.js"] } } }
Cursor Settings > MCP
{ "mcpServers": [ { "name": "resto", "command": "node", "args": ["/absolute/path/to/resto/dist/index.js"] } ] }
~/.codeium/windsurf/mcp_config.json
{ "mcpServers": { "resto": { "command": "node", "args": ["/absolute/path/to/resto/dist/index.js"] } } }
.vscode/mcp.json
{ "servers": { "resto": { "type": "stdio", "command": "node", "args": ["/absolute/path/to/resto/dist/index.js"] } } }
Replace /absolute/path/to/ with your actual installation path
